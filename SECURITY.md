# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Use GitHub's private reporting instead: open the repository's **Security** tab, choose
**Report a vulnerability**, and describe what you found and how to reproduce it.

You can expect a first reply within a few days. Once a fix is released you will be credited
in the changelog, unless you prefer to stay anonymous.

## What counts

Score247 works offline and keeps its data on your phone, so the main risks are things like:

- another app being able to read the match data or the shared pictures
- a crash that can be triggered by crafted data
- a problem in a library the app depends on

## What does not count

Mistakes in cricket scoring are normal bugs, not security issues. Please report those as
regular issues.
